## Model Fallback Chains

Each agent has a fallback chain. If the primary model is unavailable, the system automatically tries the next model:

```
architect: Qwen3 Coder 480B -> Kimi K2.5 -> GLM-4.5 -> DeepSeek R1 -> DeepSeek V3.2
engineer: DeepSeek V3.2 -> Llama 3.3 70B -> Qwen3 Coder 480B -> GPT-OSS 120B
strategist: DeepSeek R1 -> Qwen3 235B Thinking -> Kimi K2-Thinking -> Hermes 4 405B
```

## Customizing Models

Override in `openengineer.json`:

```json
{
  "agents": {
    "architect": {
      "model": "nebius/moonshot-ai/Kimi-K2.5",
      "fallback_models": [
        { "model": "nebius/Qwen/Qwen3-Coder-480B-A35B-Instruct" },
        { "model": "nebius/deepseek-ai/DeepSeek-R1-0528" }
      ]
    }
  }
}
```
