Open Engineer is a plugin for [OpenCode](https://opencode.ai) that transforms a single AI agent into a coordinated team of 10 specialized agents, each powered by a different open-source model via [Nebius Token Factory](https://tokenfactory.nebius.com).

## Why Open Engineer?

Most AI coding tools use one model for everything. That's like hiring one person to be your architect, engineer, QA lead, and designer. Open Engineer gives you specialists:

- **Architect** plans with Qwen3 Coder 480B
- **Engineer** builds with DeepSeek V3.2
- **Strategist** reasons with DeepSeek R1
- **QA Engineer** reviews with Hermes 4 405B
- **Designer** handles visuals with Qwen2.5 VL 72B

Each agent uses the best open-source model for its role. 12 different model makers. Zero vendor lock-in.

## How It Works

```
User Request
    |
[Intent Gate] -- classifies what you want
    |
[Architect] -- main orchestrator, plans and delegates
    |
    +-> [Strategist] -- deep reasoning and planning
    +-> [Engineer] -- autonomous code execution
    +-> [Product Manager] -- interview-based planning
    +-> [Technical Lead] -- todo orchestration
    +-> [Analyst] -- fast codebase exploration
    +-> [Librarian] -- documentation search
    +-> [Designer] -- visual/UI tasks
    +-> [Consultant] -- architecture advice
    +-> [QA Engineer] -- plan review and validation
    +-> [Junior Architect] -- lighter coding tasks
```

When the Architect delegates, it picks a **category** not a model. The category automatically routes to the right model and prompt.

## Quick Start

```bash
npm install openengineer
```

Add to your `opencode.json`:

```json
{
  "plugin": ["openengineer"],
  "provider": {
    "nebius": {
      "name": "Nebius Token Factory",
      "npm": "@ai-sdk/openai-compatible",
      "options": {
        "baseURL": "https://api.tokenfactory.us-central1.nebius.com/v1"
      }
    }
  }
}
```

Then start OpenCode and your agent team is ready.
