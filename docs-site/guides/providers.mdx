Open Engineer defaults to open-source models via Nebius Token Factory. You can add additional providers for fallback or specific use cases.

## Nebius Token Factory (Default)

All built-in agent models use the `nebius/` prefix and route through Token Factory.

### Setup

1. Create an account at [tokenfactory.nebius.com](https://tokenfactory.nebius.com)
2. Generate an API key
3. Set the environment variable:

```bash
export NEBIUS_API_KEY="your-key-here"
```

4. Add the provider to `opencode.json`:

```json
{
  "provider": {
    "nebius": {
      "name": "Nebius Token Factory",
      "npm": "@ai-sdk/openai-compatible",
      "options": {
        "baseURL": "https://api.tokenfactory.us-central1.nebius.com/v1"
      }
    }
  }
}
```

```json
{
```

## Adding Other Providers

You can add any OpenAI-compatible provider alongside Nebius:

### Ollama (Local Models)

```json
{
  "provider": {
    "ollama": {
      "name": "Ollama",
      "npm": "@ai-sdk/openai-compatible",
      "options": {
        "baseURL": "http://127.0.0.1:11434/v1"
      },
      "models": {
        "gemma4-26b": { "name": "gemma4-26b" }
      }
    }
  }
}
```

### OpenRouter

```json
{
  "provider": {
    "openrouter": {
      "name": "OpenRouter",
      "npm": "@ai-sdk/openai-compatible",
      "options": {
        "baseURL": "https://openrouter.ai/api/v1"
      }
    }
  }
}
```

## Using Multiple Providers

You can mix providers across agents:

```json
{
  "agents": {
    "architect": {
      "model": "nebius/Qwen/Qwen3-Coder-480B-A35B-Instruct"
    },
    "analyst": {
      "model": "ollama/gemma4-26b"
    }
  }
}
```
