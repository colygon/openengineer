## Prerequisites

- [OpenCode](https://opencode.ai) installed (`npm install -g opencode`)
- A [Nebius Token Factory](https://tokenfactory.nebius.com) API key

## Install

```bash
npm install openengineer
```

## Configure

Edit `~/.config/opencode/opencode.json`:

```json
{
  "$schema": "https://opencode.ai/config.json",
  "model": "nebius/deepseek-ai/DeepSeek-V3.2",
  "plugin": ["openengineer"],
  "provider": {
    "nebius": {
      "name": "Nebius Token Factory",
      "npm": "@ai-sdk/openai-compatible",
      "options": {
        "baseURL": "https://api.tokenfactory.us-central1.nebius.com/v1"
      }
    }
  }
}
```

Set your API key:

```bash
export NEBIUS_API_KEY="your-key-here"
```

## Use

Start OpenCode:

```bash
opencode
```

Your agent team is now active. The Architect agent orchestrates work across all 10 specialized agents automatically.

### Working Modes

<Tabs>
  <Tab title="Auto Mode">
    Just describe what you want. The Architect classifies your intent and delegates to the right agents.

    ```
    Add a login page with email/password authentication
    ```
  </Tab>
  <Tab title="Plan Mode">
    Press **Tab** to enter planning mode. The Product Manager interviews you, builds a detailed plan, then the Technical Lead executes it.

    ```
    @plan "refactor the authentication system to use JWT"
    ```
  </Tab>
  <Tab title="Direct Agent">
    Call a specific agent directly:

    ```
    @strategist "should we use Redis or Memcached for session caching?"
    ```
  </Tab>
</Tabs>

## Verify

Check your agents are loaded:

```bash
opencode debug config | grep -A2 '"agent"'
```

You should see the Architect prompt mentioning "Open Engineer" and your configured agents.
