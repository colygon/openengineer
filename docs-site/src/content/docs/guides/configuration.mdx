## Config Files

Open Engineer uses JSONC (JSON with comments) for configuration. Files are loaded in this order, with later files overriding earlier ones:

1. **User config**: `~/.config/opencode/openengineer.json` (or `.jsonc`)
2. **Project config**: `.opencode/openengineer.json` (or `.jsonc`)

<Note>
  Legacy config file names (`oh-my-openagent.json`, `oh-my-opencode.json`) are still recognized during the migration period.
</Note>

## Schema

Add the `$schema` field for editor autocompletion:

```json
{
  "$schema": "https://raw.githubusercontent.com/colygon/openengineer/dev/assets/openengineer.schema.json"
}
```

## Agent Overrides

Override any agent's model, temperature, or prompt:

```json
{
  "agents": {
    "architect": {
      "model": "nebius/moonshot-ai/Kimi-K2.5",
      "temperature": 0.7,
      "prompt_append": "Always write tests for new code."
    },
    "analyst": {
      "model": "nebius/google/Gemma-3-27b-it"
    }
  }
}
```

### Available Override Fields

| Field | Type | Description |
|---|---|---|
| `model` | string | Primary model ID |
| `fallback_models` | array | Fallback model chain |
| `temperature` | number | Sampling temperature (0-2) |
| `top_p` | number | Nucleus sampling parameter |
| `maxTokens` | number | Max output tokens |
| `prompt_append` | string | Text appended to system prompt |

## Disabling Features

```json
{
  "disabled_agents": ["junior-architect"],
  "disabled_hooks": ["comment-checker"],
  "disabled_tools": ["interactive_bash"]
}
```

## Auto Loop Configuration

```json
{
  "auto_loop": {
    "enabled": true,
    "max_iterations": 50,
    "cooldown_seconds": 5
  }
}
```

## Git Configuration

```json
{
  "git_master": {
    "commit_footer": true,
    "include_co_authored_by": true,
    "git_env_prefix": "GIT_MASTER=1"
  }
}
```

## Experimental Features

```json
{
  "experimental": {
    "disable_env_context": false,
    "safe_hook_creation": true,
    "hashline_edit": false
  }
}
```

## Environment Variables

| Variable | Description |
|---|---|
| `NEBIUS_API_KEY` | Nebius Token Factory API key |
| `OE_DISABLE_POSTHOG` | Disable telemetry (`1` or `true`) |
| `OE_SEND_ANONYMOUS_TELEMETRY` | Disable telemetry (`0` or `false`) |
| `OE_OPENCLAW_DEBUG` | Enable OpenClaw debug logging |

## Full Example

```json
{
  "$schema": "https://raw.githubusercontent.com/colygon/openengineer/dev/assets/openengineer.schema.json",

  "agents": {
    "architect": {
      "model": "nebius/Qwen/Qwen3-Coder-480B-A35B-Instruct"
    },
    "engineer": {
      "model": "nebius/deepseek-ai/DeepSeek-V3.2"
    }
  },

  "categories": {
    "quick": {
      "model": "nebius/google/Gemma-3-27b-it"
    }
  },

  "auto_loop": {
    "enabled": true
  },

  "git_master": {
    "commit_footer": true,
    "include_co_authored_by": true
  }
}
```
